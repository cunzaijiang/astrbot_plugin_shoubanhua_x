# 🎨 手办化x (AstrBot Plugin Shoubanhua-X)

> 🚀 **终极绘图缝合怪，支持第三方 OpenAI 绘图 / Google Gemini 官方格式，文生图 / 图生图 / 人设写真 / 批量处理 / PDF 导出全能插件。**  
> 🌟 **全新搭载 Neo-Brutalism（新丑风）高颜值 WebUI 独立管理控制台、多供应商高可用故障转移、毫秒级 WebP 缩略图画廊与智能磁盘存储管理！**

---

## ⚡ 核心特性一览

- 🖥️ **Neo-Brutalism 独立 Web 控制台**：内嵌于 AstrBot 面板，无需配置任何外部服务，开箱即用。
- 🌐 **多供应商高可用故障转移 (Failover)**：主供应商异常时根据自定义失败阈值（1~3 次）自动无缝切换至备用渠道，保障生图 100% 可用。
- 🖼️ **毫秒级极速画廊 & 内置高清灯箱 (Lightbox)**：
  - 采用服务端异步并发 WebP 缩略图引擎（体积骤降 98.5%），30张/页秒开。
  - 内置浮层灯箱全屏预览，支持按需异步拉取高清原图。
- 💾 **磁盘存储配额与智能清理**：
  - 支持自定义存储上限（GB）与超限自动清理比例。
  - 支持一键清理 50% 最旧图片、100% 全量清空，以及单张图片独立点选删除。
- ⚡ **真实生图连通性测试 (Test API)**：一键对当前配置的绘图模型发送真实渲染测试，实时反馈耗时与生成效果。
- 🧠 **LLM 智能感知与上下文感知**：智能分析 20 轮会话，自动区分文生图、图生图、人设自拍或连贯改图需求。
- 📊 **多维配额与调用统计**：支持用户/群组独立调用统计、每日签到奖励、精确次数扣减与失败自动全额退还。

## 📥 安装方法

### 方式一：AstrBot 插件市场安装（推荐）
在 AstrBot 控制台「插件市场」搜索 **`手办化x`** 或 `astrbot_plugin_shoubanhua` 点击安装。

### 方式二：Git 仓库链接一键安装
在 AstrBot 控制台插件管理中添加 Git 地址：
```text
https://github.com/cunzaijiang/astrbot_plugin_shoubanhua_x
```

## 🖼️ Web 控制台功能介绍

安装后点击 AstrBot 左侧导航中的 **「手办化x」** 即可进入全新 Neo-Brutalism Web 控制台：

1. **📊 仪表盘概览 (Overview)**：查看今日活跃用户、今日成功生图调用总数、历史图片总量与磁盘占用，并在画廊中浏览/清理所有生成的图片。
2. **🎨 生图工作台 (Studio)**：支持在网页端直接上传参考图、输入提示词并实时调试生成效果。
3. **📋 预设管理 (Presets)**：可视化查看、编辑、新增所有内置与自定义预设提示词（Prompt）。
4. **⚙️ 插件配置 (Config)**：在线修改模型名称、分辨率、存储容量上限（GB）、清理比例等参数，实时热重载。
5. **🌐 供应商与故障转移 (Providers)**：配置多套备用 API 渠道及重试阈值，高并发下无缝容灾。
6. **🔑 密钥池管理 (Key Pool)**：可视化管理多条 API Key，支持一键发送测试生图验证连通性与模型耗时。
7. **📈 额度与统计 (Quota)**：实时查看所有用户与群组的剩余配额及今日调用量，支持管理员一键快捷充值。

## ⚙️ 配置文件参数说明

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `interface_mode` | string | `openai_image` | 接口模式 (`openai_image` / `openai_chat` / `gemini_official`) |
| `base_url` | string | - | 中转 API 接口地址 |
| `api_keys` | string | - | API Key 池（每行一个） |
| `model` | string | `gpt-image-2` | 默认生图模型 |
| `text_to_image_model` | string | - | 文生图专用模型（留空继承默认模型） |
| `image_storage_max_gb` | float | `5.0` | 历史图片存储上限 (GB) |
| `image_cleanup_ratio` | float | `0.5` | 超限自动清理比例 (0.1 ~ 0.9) |
| `provider_failover_threshold` | int | `1` | 供应商失败重试与故障转移阈值 (1 ~ 3次) |
| `backup_providers` | list | `[]` | 备用供应商列表 |
